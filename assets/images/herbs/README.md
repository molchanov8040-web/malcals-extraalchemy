# Изображения для справочника трав и лириума

Эта папка предназначена для иконок предметов компендиума **«Malcal's ExtraAlchemy — Травы и лириум»**.

## Правила файлов

1. Помещайте изображения непосредственно в `assets/images/herbs/`.
2. Используйте формат `webp`; рекомендуется квадрат не меньше 256×256 px.
3. Имя файла должно точно совпадать с записью ниже: латиница в нижнем регистре, дефисы вместо пробелов. Не используйте кириллицу, пробелы и апострофы.
4. После добавления или замены изображения обновите страницу Foundry (`Ctrl+F5`). При следующей загрузке мира модуль синхронизирует записи компендиума.
5. Картинка с правильным именем обновит иконку существующей записи, но сама по себе не добавит новый ингредиент. Для нового ингредиента нужна запись в `EA.herbSeeds()` в `scripts/library-v13.js` с тем же именем в поле `f`.
