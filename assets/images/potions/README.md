# Изображения готовых зелий

Каталог изображений для компендиума «Готовые зелья».

Используйте локальные пути модуля:

```text
modules/malcals-extraalchemy/assets/images/potions/<id>.webp
```

Требования к файлам:

- формат `.webp`;
- строчные латинские буквы и дефисы в имени;
- без пробелов, кириллицы и специальных символов;
- рекомендуется квадратное изображение 256×256 или 512×512.

## Ожидаемые изображения зелий

### Целебные припарки

- `small-healing-poultice.webp` — «Малая целебная припарка», восстанавливает `2d4 + 2` ПЗ;
- `healing-poultice.webp` — «Целебная припарка», восстанавливает `4d4 + 4` ПЗ;
- `large-healing-poultice.webp` — «Большая целебная припарка», восстанавливает `8d4 + 8` ПЗ;
- `strong-healing-poultice.webp` — «Сильная целебная припарка», восстанавливает `10d4 + 20` ПЗ.

### Зелья лириума

- `minor-lyrium-potion.webp` — «Малое Зелье лириума», восстанавливает 1 круг заклинаний;
- `ordinary-lyrium-potion.webp` — «Обычное Зелье лириума», восстанавливает 2 круга заклинаний;
- `large-lyrium-potion.webp` — «Большое Зелье лириума», восстанавливает 3 круга заклинаний;
- `potent-lyrium-potion.webp` — «Сильнодействующее Зелье лириума», восстанавливает 5 кругов заклинаний.

Если файл отсутствует, модуль использует стандартную иконку Foundry. Пользовательские предметы из других модулей сохраняют изображение, полученное из исходного компендиума.
